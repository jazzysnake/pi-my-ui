Variant A — “Console”

Thesis: keep the terminal lineage — one dense monospace stream where every surface is a compact hairline-separated row and the transcript itself is the interface.

Optimises for: density and fast scanning; most of a long session and its status on one phone screen; familiar to a pi TUI user.

Trades away: touch comfort, generous tap targets, and the glance-level separation that helps distinguish message kinds. Navigation leans on commands, not big affordances.

Found it. In applyDelta we append each delta onto partial.text, but on resync the snapshot goes through the same reducer without clearing that buffer first. So the snapshot's copy of the message lands after the partial already there — two copies of the same id.

export function apply(state, event) {
  if (event.kind === 'snapshot') return replace(state, event);
  return mergeDelta(state, event);
}
