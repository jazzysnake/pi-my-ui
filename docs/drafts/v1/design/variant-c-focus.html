Variant C — “Focus”

Thesis: strip the chrome — the transcript is plain type on near-black, and every secondary surface (sidebar, tree, palette, agent list) is a sheet you pull up, not a thing that lives on screen.

Optimises for: one-handed reach and an immersive read; the composer is the biggest target on screen and the only permanent control cluster.

Trades away: at-a-glance status and discoverability — the pill, indicators and navigation sit further from the message you are reading than in the other two variants.
